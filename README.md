# 疑似GPS 地図ツール

自作の位置ゲーを、実際に歩かずにテストするための道具。
PC の地図上でピンを動かすと、その位置が自作ゲームの「現在地」になる。
PC のブラウザだけでも、同じ Wi-Fi のスマホ実機でも試せる。

## 起動

`地図ツールを起動.vbs` をダブルクリックすると、中継サーバー（`node server.js`）が立ち上がり、
ブラウザで地図ツールが開く。

- 初回は Windows ファイアウォールが Node の通信許可を聞いてくる。スマホから使うので **プライベートネットワークを許可** する。
- 「テスト用ゲームを開く」を押すと、近くのダンジョンを探すサンプル画面が別タブで開く。
  2 つのウィンドウを横に並べると、ピンの動きがゲームに届く様子が見える。
- **`server.js` を更新したら、動いているサーバーを止めてから起動し直す**。`地図ツールを起動.vbs` は、サーバーがすでに動いていると
  新しい方が黙って起動に失敗し、古いサーバーが残る（画面は新しくなるのに保存が 404 になる・地図ツールに「中継サーバーが古いままです」と出る）。

## スマホ（iPhone / Android）で試す

1. スマホを **PC と同じ Wi-Fi** につなぐ。
2. 地図ツールの右下「スマホで開く」に出る QR をスマホのカメラで読む（URL 直接入力でも可）。
3. スマホのブラウザでテスト用ゲームが開き、PC でピンを動かすと現在地が変わる。

自作ゲームを試すときは、URL の `demo-game.html` を自分の HTML ファイル名に置き換える。
`?fakegps=1` は付けたまま。

## 操作

| 操作 | 動き |
|---|---|
| 地図をクリック | その地点へ、選んだ速さで移動する（ワープなら瞬間移動） |
| ピン（戦士の絵）をドラッグ | その場所へ置く |
| ↑↓←→ / WASD | 押している間だけ進む（ワープを選んでいるときは時速 40km） |
| 座標へ飛ぶ | `38.260, 140.882` や Google マップの URL を貼って瞬間移動 |
| GPSのブレ | 本物の GPS のように ±10m の範囲で位置が揺れる |

速さは ワープ / 歩き 4km/h / 走り 10km/h / 自転車 15km/h / 車 40km/h / 早送り 400km/h。

## ダンジョンを置く（歩かずに確認する）

1. 地図ツール右側の「ダンジョンを置く」で、名前・種類・半径（既定 40m）を決める
2. **「地図に置く」を押してから地図をクリック** → その場所に置かれる（もう一度押すと配置モードを抜ける）
3. 一覧の **「飛ぶ」** を押すと、ピンがその場所へ瞬間移動する ＝ **現場に着いた扱いになる**
4. ゲーム画面に「着いた！」と入るボタンが出る → 押すとダンジョンが展開される

置いた内容は `dungeons.json` に保存され、つながっているゲーム（スマホ含む）が数秒で拾い直す。
一覧の「削除」で消せる。配置中はピンが動かないので、置く操作と歩く操作は混ざらない。

## クエスト主を置く（声を掛けて受注 → 目的地へ向かう）

画面は 2 つある。**PC の地図ツール**（置く側）と、**テスト用ゲーム**（遊ぶ側。PC の別タブか、スマホ）。

地図ツール（PC）でやること:

1. 右側のパネルの「クエスト主を置く（目的地のダンジョンとセット）」で、名前（空でもよい）・見た目・目的地の種類を選ぶ
2. **「クエスト主を置く」ボタン**を押す → 地図を 1 回クリック（クエスト主の場所）→ もう 1 回クリック（目的地のダンジョンの場所）
3. すぐ下の一覧の **「主へ飛ぶ」** でピンがクエスト主の所へ、**「目的地へ飛ぶ」** で目的地のダンジョンへ瞬間移動する

テスト用ゲームで起きること:

1. 地図にクエスト主（頭の上に **!**）が出る。目的地のダンジョンは、まだ地図に出ない
2. クエスト主に 30m まで近づくと、画面下に **「💬 ○○ に話しかける」** ボタンが出る（地図のクエスト主をタップしても話せる）
3. 依頼の言葉と報酬が出る → **「📜 引き受ける」** を押すと目的地のダンジョンが地図に現れ、そこまでの点線と、画面下に「次に向かう場所と距離」が出る（**「断る」** なら何も変わらない）
4. 目的地に近づいて入り、ボスまで倒す（負けたり逃げたりしても依頼は受けたまま。攻略するまで何度でも挑める）
5. クエスト主の頭の上が **?** になる → 戻って話しかけ、**「💰 報酬を受け取る」** で報酬（ゴールド・経験値）が入る。目的地のダンジョンは地図から消える

- 頭の上の印: **!** = 依頼あり / **…** = 受注中 / **?** = 報告できる / 印なし = 達成済み
- クエスト主の名前には依頼のグレードが付く（例: **村の長老（LV1）**）。グレード = 目的地のダンジョンの危険度（★ の数・1〜5）。
  地図ツールのクエスト主の一覧・ゲームの「💬 話しかける」ボタン・印をタップした案内・会話の名前・「○○ に報告する」の行に出る
- 依頼の進み具合は、その端末のブラウザ（localStorage `locgame.quests.v1`）に保存する。同じ依頼をもう一度試すときは、地図ツールでクエスト主を「削除」して置き直す
- 地図ツールには受注前の目的地も全部見える（紫の点線でクエスト主とつながり、印に 📜 が付く）。ダンジョンの一覧には出さず、クエスト主の一覧にまとめる
- 依頼の言葉と報酬は目的地の種類ごとに `quest.js` の `REQUESTS`、見た目は `LOOKS`（`sprites/npc/` の 11 人）にある
- クエスト主の絵は、ダンジョンファイターズ（同じ作者の自作ゲーム）の歩きの絵から、1 コマ 48×72 の横 6 コマに切り出したもの

## テスト用ゲームの画面

入る前は **地図の画面**。自分（足元に金の輪がある戦士の絵。東へ進むと右、西へ進むと左を向く）が真ん中にいて、動くと地図がついてくる。

- ダンジョンは種類ごとの入口の絵と「入れる範囲」の円で出る。範囲に入ると絵が光り、下の「入る」ボタンか **絵のタップ** で入れる。依頼の目的地には 📜、攻略済みには ✅ が付く
- 絵をタップすると名前・危険度・距離が出る（「あと ○ m 近づくと入れる」）
- 指で地図を動かすと追いかけるのをやめる。◎ ボタンで現在地へ戻る
- 地図が読めないとき（ネットにつながらない等）は、下の一覧だけで遊べる

地図タイルは地図ツールと同じ OpenStreetMap（API キー不要）を、暗く茶色に色づけして使う。
OSM のタイルは開発・少人数向けなので、公開して多くの人が遊ぶ段になったら別のタイル配信に切り替える。

## ダンジョンの中身（テスト用ゲーム）

入ると、D&D 風のターン制で部屋を 1 つずつ攻略する（入口 → 部屋ごとに戦う → 最後の部屋はボス）。

- 部屋の数（敵の数 2〜5）と顔ぶれは **ダンジョンの id で決まる**。同じダンジョンなら、誰が何度入っても同じ
- 種類（ゴブリンの巣穴〜竜の住処）ごとに敵と危険度（★1〜5）が違う。一覧にも危険度が出る
- 攻撃は **🎲 d20（20面サイコロ）＋ 命中の上乗せ が相手の防御以上なら命中**。20 の目は会心（ダメージのサイコロを倍振り）、1 の目は必ず外れ
- 回復薬は入るたびに 3 個。HP と回復薬は、入り直すと満タンに戻る
- 倒した敵の経験値は、途中で逃げても力尽きても持ち帰れる。宝箱（ゴールド）は最後まで攻略したときだけ
- **最後まで攻略したダンジョン（✅）には、もう入れない**。範囲に入っても「入る」ボタンが出ず、印も光らない（負けたり逃げたりしたときは、何度でも入り直せる）。
  同じ所をもう一度試すときは、地図ツールで削除して置き直す
- 冒険者の Lv・経験値・ゴールド・攻略済みの印（✅）は、その端末のブラウザ（localStorage）に保存する。サーバーには送らない

敵やダンジョンの種類を増やすときは、`dungeon.js` の `MONSTERS` と `LINEUPS` に行を足す。画面側（`demo-game.html`）は触らなくてよい。

## 自作ゲームへの組み込み

1. ゲームの HTML の `<head>` で、ゲーム本体より先に `fake-gps.js` を読み込む
   ```html
   <script src="fake-gps.js"></script>
   ```
2. ゲームは普段どおり `navigator.geolocation.watchPosition()` などで位置を取る
3. テストするときだけ、中継サーバーが配る URL（`http://<PCのIP>:8790/…`）に `?fakegps=1` を付けて開く

`?fakegps=1` が無ければ何も差し替えないので、スマホ実機では本物の GPS がそのまま使われる。
一度付けると、同じタブの中でページを移っても有効なまま。`?fakegps=0` で解除する。

## ファイル

| ファイル | 役割 |
|---|---|
| `server.js` | 中継サーバー（静的配信 ＋ 位置の中継）。Node 標準だけで動く（追加インストール不要） |
| `map.html` | 地図ツール本体（地図は OpenStreetMap） |
| `fake-gps.js` | 自作ゲームに読み込ませる差し替え部品 |
| `demo-game.html` | テスト用ゲームの画面（近くのダンジョンを表示・入って戦う） |
| `dungeon.js` | ダンジョンの中身（敵の顔ぶれ・サイコロ・戦いのルール）。画面には触らない |
| `quest.js` | クエストのルール（クエスト主の見た目・依頼の言葉と報酬・受注から報告までの進み方）。画面には触らない |
| `sprites/npc/` | クエスト主の絵（1 コマ 48×72 × 横 6 コマ）。ダンジョンファイターズの素材から切り出して流用 |
| `sprites/hero/` | 自分の絵（同じ大きさ）。ダンジョンファイターズの戦士の歩きの絵から切り出して流用。地図ツールのピン・ゲームの地図・上の行・戦闘の自分の欄で使う。差し替えは `demo-game.html` と `map.html` の CSS `.npc.hero` |
| `sprites/dungeon/` | ダンジョンの入口の絵（種類ごとに 1 枚・384×384）。Codex に描かせたもの。ゲームの地図は 96×96、地図ツールは 64×64 で出し、接地線（下から 5% ほど上）の中央が地点に来る。種類を増やすときは同じ名前で絵を足し、`demo-game.html` の `KIND_EMOJI` と `map.html` の `KINDS` にも足す |
| `dungeons.json` | 置いたダンジョンとクエスト主の保存先（地図ツールが書き、ゲームが読む） |
| `地図ツールを起動.vbs` | サーバー起動＋ブラウザを開くランチャー |
| `tools/verify_map_tool.js` | ヘッドレス検証 |
| `dev-meetings/` | 開発会議の記録（1 議題 1 ファイル）。このフォルダで Claude Code に「開発会議」と頼むと始まる。スキル本体は `.claude/skills/dev-meeting/` |

## 仕組みと制限

- 地図ツールが送ったピンの位置を、中継サーバーが Server-Sent Events でゲームへ配る。
  後から開いたゲームにも、サーバーが最後の位置をすぐ渡す
- 差し替わるのは `fake-gps.js` を読み込んだ自作ゲームの中だけ。スマホや PC 本体の GPS、ほかのアプリには影響しない
- 有効になるのは **localhost と自宅 LAN（プライベートIP・.local）から開いたときだけ**。
  公開先（GitHub Pages など HTTPS の外部ホスト）では `?fakegps=1` を付けても無効なので、遊ぶ人はごまかせない
- 移動は直線。道路に沿って歩く機能はまだ無い
- 地図は OpenStreetMap を使う（ネット接続が必要）

## 検証

```
node tools/verify_map_tool.js            # 画面を出さずに検証（server.js を自動で起動して試す）
node tools/verify_map_tool.js --headful  # Chrome の画面を出して検証
```

puppeteer-core と Chrome を使う。終了コードは 0 = 全項目合格 / 1 = 不合格あり / 2 = 準備に失敗。
