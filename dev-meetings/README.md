# dev-meetings — 開発会議の記録

`dev-meeting` スキル（`.claude/skills/dev-meeting/`）で開いた開発会議の出力を、後から見返せるように保存するフォルダ。
位置RPG制作のフォルダで Claude Code に「開発会議」「会議を開いて」「次に何を作るべきか相談したい」などと頼むと始まる。

## 会議の流れ

1. **第1段（候補出し）**: 4 人が毛色の違う候補を 3〜4 個出す → 慶彦さんが 1 つ選ぶ
2. **第2段（実装計画）**: 選んだ案の開発計画書を作る → 慶彦さんが直す・承認する
3. **実装（会議の外）**: この窓でそのまま頼むか、窓更新して新しい窓で頼む

## 運用ルール

- **1 議題 = 1 ファイル**。命名は `YYYY-MM-DD_<議題の短いslug>.md`。
- **第1段** を開いたら、対話ログ＋実装候補一覧をそのファイルに保存する。
- **第2段** の開発計画書は、**同じファイルに追記**する（第1段の下に続ける）。
  これで「候補 → 決定 → 開発計画書」が 1 ファイルで時系列に追える。
- 会議のあとで前提が崩れたと分かったら、候補を黙って差し替えず、冒頭に「会議後に判明したこと」の節を立てて残す。
- 決定は記号だけで書かない（「③」ではなく「候補③ ○○」）。
- チャットに表示した内容と保存内容は同一でよい。

## ファイル構成の目安

```
dev-meetings/
  README.md                      ← このファイル
  YYYY-MM-DD_<議題>.md            ← 会議ごとに 1 ファイル（第1段 → 第2段を追記）
```

## 関連

- スキル本体: `.claude/skills/dev-meeting/SKILL.md`
- ペルソナ定義: `.claude/skills/dev-meeting/references/agents.md`
- 出力テンプレート: `.claude/skills/dev-meeting/references/output-format.md`
- 元はダンジョンファイターズの同名スキル（2026-09-15 に位置RPG 用へ書き換え）。位置RPG の会議からあちらのファイルは読まない
- 位置RPG制作は git で管理していないので、別の PC へ持っていくときは `.claude\` フォルダと `dev-meetings\` をまとめてコピーする
